# Desarrollo para Dispositivos Inteligentes

Este repositorio es para las prácticas de la materia **Desarrollo para dispositivos inteligentes**.

Estructura propuesta:

- `practicas/p1.1/` → Entregable de la práctica P1.1 (investigación de dispositivos y sistemas operativos).
- Más carpetas de prácticas se irán agregando después (`p1.2`, `p2.1`, etc.).

Cada práctica debe incluir:

- Documento principal (Markdown o Word) con la investigación.
- Capturas de pantalla necesarias.
- Archivo `IA.md` o sección al final del documento donde se declare el uso de herramientas de IA.
